# Novas Features Planejadas

## Curto Prazo

### Processamento de Arquivos
- [ ] Suporte a multiplas paginas de PDF
- [ ] OCR para PDFs escaneados (imagem dentro de PDF)
- [ ] Suporte a DOCX (Word)
- [ ] Suporte a RTF
- [ ] Compressao automatica de imagens grandes

### Traducao
- [ ] Deteccao automatica do tipo de exame

- [ ] Glossario personalizavel

- [ ] Cache de respostas para laudos identicos
- [ ] Modo offline com modelo local (Ollama)
- [ ] Salvamento temporario do resultado na sessao
